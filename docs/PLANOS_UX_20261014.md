## Limitações explícitas
- Ficha do operador: a RPC atual não retorna a quantidade agendada. Exibe “—” e orientação para consultar agenda; não inventa zero. Admin e ficha de veículo usam o valor existente em get_client_plan_control.
- Não foi acrescentada edição da quantidade contratual de estéticas a esta tela, pois é uma alteração comercial ligada ao faturamento; o editor reorganiza a quantidade mensal de benefícios. Fluxos contratuais existentes permanecem intactos.
- Registro manual independente, sem atendimento vinculado, continua permitido pelo fluxo original. Responsável é registrado pelo backend. Portanto a exigência de vínculo obrigatório a atendimento ainda não está integralmente atendida.
- Vigência disponível por mês, não por dia. Histórico completo consultável por competência. Consultas históricas existentes possuem limites de registros, não removidos nesta alteração.
- Frequências a cada N visitas dependem do histórico concluído recebido; não foi alterado o contrato de dados das RPCs.
- Não houve teste em sessão autenticada nem aparelho Android real. Entrega é prévia para avaliação, não liberação final para produção.
